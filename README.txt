BLOCORA GİZLİLİK SİTESİ — YAYIN REHBERİ

Sitenin dosyaları:
- index.html (Türkçe / English, responsive)
- blocora-logo.webp (uygulama logosu)

YAYINLAMADAN ÖNCE ZORUNLU:
1. index.html dosyasında [İLETİŞİM_EPOSTASI_EKLE] ve [ADD_CONTACT_EMAIL] metinlerini gerçek bir destek e-posta adresiyle değiştirin.
2. Gizlilik iddialarının App Store'a gönderilecek SON uygulama sürümüyle aynı olduğunu doğrulayın.
3. Bunları bitirdikten sonra index.html içindeki iki yayın öncesi uyarı kutusunu kaldırın (id=notice-tr ve id=notice-en).
4. Apple için uygulamanın Ayarlar ekranına gizlilik politikası bağlantısını ekleyin.

GITHUB PAGES İLE ÜCRETSİZ YAYIN:
1. GitHub hesabınızda yeni PUBLIC repository oluşturun (ör. 'blocora-privacy').
2. index.html ve blocora-logo.webp dosyalarını bu repository'nin ana dizinine yükleyin.
3. Repository -> Settings -> Pages -> Build and deployment -> Deploy from a branch.
4. Branch 'main', folder '/ (root)' seçin ve Save yapın.
5. GitHub Pages sayfasının oluşturduğu gerçek HTTPS adresini açarak kontrol edin.
6. Bu gerçek adresi App Store Connect -> App Privacy -> Privacy Policy URL alanına girin.

NOT: Gizlilik sitesini yayımlamak, oyunun kaynak kodlarını yayımlamanızı gerektirmez. GitHub'a yalnızca bu iki site dosyasını koyun; blocora.zip dosyasını yüklemeyin.
